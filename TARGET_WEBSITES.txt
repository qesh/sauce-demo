 API AUTOMATION (REST Assured)
---------------------------------------------------------------------

3. Restful Booker (CRUD + Token Auth)
   Base URL:  https://restful-booker.herokuapp.com
   Docs:      https://restful-booker.herokuapp.com/apidoc/index.html
   Auth:      admin / password123
   Endpoints: GET    /ping                 - health check (returns 201)
              POST   /auth                 - create token
              GET    /booking              - list booking ids
              GET    /booking/{id}         - get booking
              POST   /booking              - create booking
              PUT    /booking/{id}         - full update   (needs token)
              PATCH  /booking/{id}         - partial update (needs token)
              DELETE /booking/{id}         - delete (needs token, returns 201)
   Notes:     - Send the token as a cookie:  Cookie: token=<token>
              - Send Accept: application/json exactly (otherwise 418 "I'm a Teapot")
              - Bad credentials still return 200 with {"reason":"Bad credentials"}

4. ReqRes (Mock REST API)

   API key:   header  x-api-key: reqres-free-v1   (requests without it are rejected)
